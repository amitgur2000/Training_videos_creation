# Chapter registry: <Product>

The living index of this site's chapters, in curriculum order. The skill reads it to resolve a chapter name, appends rows for new chapters, and updates the language status after every run.

## Rules

- **Each chapter is a folder, `training/<site>/<NN>_<slug>/`,** holding one `<NN>_<slug>.record.py` and a folder per language (`he/`, `en/`, ...) with the script and each device's video. The number is two digits: the chapter's place in the curriculum.
- **New chapters get the next free number** unless the user picks one. Existing numbers and folders are never renumbered.
- **Start page:** the site's `start_page`, unless the chapter is about something before login or elsewhere.
- **Status per language:** `drafted` (the script is written), `produced` (the videos are made), `verified` (the user watched them and signed off).
